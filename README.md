# La Pénombre — boutique e-commerce

Base de site e-commerce en français pour la France. Coordonnées fournies : 62 rue du Rochoir, 62430 Sallaumines — 06 13 33 40 83.

Les pages légales contiennent encore des champs obligatoires à compléter : identité juridique, SIRET, email, hébergeur, directeur de publication, adresse de retour, médiateur et politique RGPD détaillée.

Avant mise en ligne : connecter un prestataire de paiement sécurisé (Stripe Checkout, Shopify Payments ou équivalent), configurer la livraison, la TVA, les factures, les emails transactionnels, les retours et les stocks. Faire vérifier les CGV et les allégations du produit par un professionnel compétent en droit français. Le site ne doit pas présenter le masque comme dispositif médical sans satisfaire aux obligations applicables.
